# STR BIM Tools

Extension pyRevit (Revit 2024 et supérieur) de Tony VARIN.

## Installation

1. pyRevit › Extensions (gestionnaire d'extensions).
2. URL Git : `https://github.com/Ameisen-Killer/STR-BIM-Tools-extensions.git`
3. Token : laisser vide (dépôt public).
4. « Ajouter et installer », puis recharger pyRevit.

## Mises à jour

Pousser les modifications sur `main`, puis bouton **Update** de pyRevit sur chaque poste.

Les fichiers `prefs.json` et `can241_*.json` sont propres à chaque poste et ne sont pas suivis.
